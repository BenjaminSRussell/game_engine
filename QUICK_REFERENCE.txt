⚠️  COMMON PITFALLS
───────────────────────────────────────────────────────────────────────────────

❌ Starting with GPU optimization
   → Get CPU version stable first (10x easier)

❌ Implementing all 269 TODOs
   → Need only 144 for MVP. Stop at "good enough"

❌ Skipping unit tests
   → Physics bugs take weeks to debug. Test-driven development!

❌ Premature SIMD optimization
   → Good algorithms beat SIMD. Profile before optimizing

❌ Implementing lock-free concurrency
   → Simple mutexes are fast enough. Only optimize if bottleneck

❌ Aiming for perfect code
   → Ugly working code beats pretty broken code. Refactor after tests

❌ Ignoring performance metrics
   → Document targets. Benchmark constantly. Know your numbers
