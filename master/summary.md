# Master Folder Summary

## Agent Rules
- Only one README is allowed: keep `README.md` at repo root and do not add any other README files.
- Do not disable files or park work in `.disabled`/backup variants; fix or integrate in-place.
- All work must happen in the codebase; do not create new TODO docs outside `master/`.
- Any task you touch must be recorded in `master/todo.csv` and reflected in `master/todo.md`.
- Remove completed tasks from `master/todo.csv` and add a completion note in `master/todo.md`.
- Avoid overlap: claim a category before edits and keep changes scoped to your assigned items.
- Consolidation is the final step after build is green; do not consolidate before a successful build.
- Read `master/master.md` before starting any work to confirm rules and workflow.
- Use `master/expectations.md` for quality and depth requirements.
